# Marketing UI Kit — Atrio

Brand surfaces that sit outside the WhatsApp bot: the landing page at `useatrio.com`, a pitch card for in-person meetings, a social post template, and an invitation card. All built on the two-color / one-typeface / no-shadow / no-gradient rules from the brand guidelines.

## Components

- `LandingHero.jsx` — full-bleed Cal hero with wordmark, tagline, tight CTA.
- `BrokerInviteCard.jsx` — invitation card (to be sent to a broker as an image).
- `PitchCard.jsx` — 30-second pitch poster.
- `SocialPost.jsx` — 1:1 social post template.
- `StatBlock.jsx` — the "50 brokers · un inventario · cero grupos saturados" big-number unit.
- `NavBar.jsx` — landing-page top bar.

## Scope

Purely visual — no interactivity beyond hover/press on the CTA. Everything obeys:
- Cal or Negro as the only background
- Geist 300 Light for titles, 400 Regular for body, 100 Thin for big numbers
- No gradients, no shadows, no emoji
- No exclamation marks in copy

## Caveats

- No real photography was supplied. Where the brand direction calls for "austere material / light / shadow" imagery, we leave labeled `LUZ · SOMBRA · MATERIAL` placeholders.
- The landing layout is a plausible interpretation consistent with the guidelines, not a recreation of a known page.
